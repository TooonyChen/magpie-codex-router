# magpie-codex-router

Keep Codex logged in with ChatGPT while model requests and the model list go
through your own OpenAI Responses-compatible gateway, via a tiny local relay.

让 Codex 保持 ChatGPT 登录，同时通过本机的一个小 relay，把模型请求和模型列表交给你自己的网关。

| 平台 | 状态 |
|---|---|
| [macOS](macOS/) | 可用 |
| [Windows](windows/) | 可用 |

安装和原理见各平台目录下的 README。
